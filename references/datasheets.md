# Valve datasheets

These are scanned datasheets hosted on Frank Philipse's archive. Each PDF was opened and its header page checked on 2026-10-10. They are linked only, not copied into this repo.

| Valve | Role in the Culture Vulture | Datasheet | Notes |
| --- | --- | --- | --- |
| **6AS6** | Distortion valve (original unit, UAD plugin) | <https://frank.pocnet.net/sheets/127/6/6AS6.pdf> (Tung-Sol) | Dual-control pentode on a miniature 7-pin base. The suppressor grid (g3) is a second control grid, which may explain the unusual P2/P3 modes. Use the plate and transfer curves to fit the Koren model. |
| **5725 / 6AS6W / 6187** | Distortion valve (Mastering Plus, Super 15) | <https://frank.pocnet.net/sheets/127/5/5725.pdf> (Tung-Sol) | Premium / ruggedised version of the 6AS6. |
| **EF86** | Input stage (original unit; per SOS and the 2005 manual) | <https://frank.pocnet.net/sheets/030/e/EF86.pdf> (Philips) | Low-noise AF pentode. A forum guess says it is triode-connected; that is unverified. |
| **M8100** | Input stage (Mastering Plus 2010, Super 15) | <https://frank.pocnet.net/sheets/129/m/M8100.pdf> (Mullard) | Special-quality low-noise RF pentode. |
| **5654** | Input stage (Mastering Plus issue 4, Super 15) | <https://frank.pocnet.net/sheets/127/5/5654.pdf> (Tung-Sol) | Premium version of the 6AK5 type. The manuals list M8100 as an equivalent. |
| **6AK5** | Equivalent listed for the input valve | <https://frank.pocnet.net/sheets/127/6/6AK5.pdf> (Tung-Sol) | Base type of the 5654. |
| **EF95** | Equivalent listed for the input valve | <https://frank.pocnet.net/sheets/030/e/EF95.pdf> (Philips) | Listed in the manuals as an equivalent. |
| **M8196** | Equivalent listed for the 5725 | <https://frank.pocnet.net/sheets/129/m/M8196.pdf> (Mullard) | Special-quality equivalent of the distortion valve. |
| **5963** | Output stage, shared twin triode | <https://frank.pocnet.net/sheets/127/5/5963.pdf> (Tung-Sol) | The manuals name the ECC82 / 12AU7 as near equivalents. |
| **ECC82** | Equivalent listed for the 5963 | <https://frank.pocnet.net/sheets/030/e/ECC82.pdf> (Philips) | Use for the output triode model if 5963 curves are too sparse. |
| **12AU7A** | Equivalent listed for the 5963 | <https://frank.pocnet.net/sheets/127/1/12AU7A.pdf> (Tung-Sol) | US designation of the ECC82. |

Not found: a datasheet for the **13D5**, which only the Mastering Plus issue 4 manual lists as the output valve, was not located on Frank's archive and is not linked.
